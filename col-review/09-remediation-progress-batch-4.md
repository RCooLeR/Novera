## Independent integration checks and follow-up fixes

The batch included a final cross-workstream review after parallel implementation. It found and resolved integration issues that were not owned by one original finding:

1. **Bindings were regenerated only after all bound Go signatures stabilized.** The final generator processed 527 packages, 13 services, 145 methods, one enum, and 75 models. The output contains BuildInfo, schema-preserving DB models, truncation reason, new DB signatures, credential states, Agent transition methods, and narrowed service surfaces.
2. **A stale legacy LLM ref could have been detached by an unrelated settings save.** Save now preserves the exact quarantined ref when provider/origin is unchanged, while an origin change still detaches it. A regression covers the unrelated-save case.
3. **Workspace remembrance was initially inside the transition barrier.** It was moved after Agent End so slow settings persistence cannot unnecessarily hold root/Agent transition ownership. Durable settings failure is still surfaced.
4. **About helper tests initially imported the full Wails/store graph in Node.** Pure identity formatting was separated from the component, avoiding a synthetic `window` dependency while retaining component type safety through generated bindings.
5. **Windows artifact race tests exposed path-inspection portability rather than an assertion bug.** Platform-specific link/reparse checks replaced the unstable path operation and retained fail-closed behavior.
6. **A direct production link test validated the new identity contract.** The built executable contained the injected `9.8.7`, `0123456789ab`, `2026-07-17T12:00:00Z`, and `validation` values; the artifact was then removed.
7. **The first lazy-loading implementation still preloaded Monaco.** The new production-entry assertion caught that explicit `manualChunks` had pulled shared React exports into the Monaco chunk. Removing that forced grouping restored natural dynamic boundaries; the manifest check now proves that EditorPane/TerminalView and Monaco/xterm dependencies are reachable only through dynamic edges and absent from initial HTML.
8. **Packaging containment was reviewed against downstream callers.** Android emulator deploy/run tasks were updated to use the explicit debug task and `Novera-debug.apk`, preventing the new production fail-closed gate and artifact rename from breaking local emulator workflows.

### Windows test-driver limitation retained explicitly

The normal `go test . ./internal/...` driver passed the root and Agent packages, then Windows security tooling suspended later newly linked `*.test.exe` children without a failing assertion or diagnostic. The same behavior also affected an attempted consolidated race rerun and left orphaned Go/test processes. Those exact validation processes were terminated after all agents had stopped.

To avoid converting an antivirus/driver deadlock into either a false failure or false success, the broad normal matrix used `go test -c` per scoped package, gave each binary a neutral name, ran it from the package source directory with a timeout, and required a zero exit status. Every test binary reported `PASS`. The later identity/config changes were revalidated in their affected normal/race packages. Targeted race suites passed in focused workstreams; a final combined all-package race rerun is not claimed.
